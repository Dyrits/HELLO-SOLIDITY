# Hello, Solidity!

A first smart contract project (+ a Counter contract), built while following the Frontend Masters course "A Tour of Web 3: Ethereum & Smart Contracts with Solidity".

## About The Project

This project contains Solidity contracts, deployment scripts and tests, set up with Hardhat and TypeScript, plus a small front-end served from `dist/`.

## Built With

- Solidity
- Hardhat (hardhat-ethers, hardhat-waffle)
- TypeScript
- Ethers.js

## Getting Started

### Prerequisites

- Node.js and yarn (a yarn.lock is included)

### Installation

```bash
yarn install
```

### Usage

```bash
yarn launch   # start a local Hardhat node
yarn deploy   # deploy the contracts to the local node
yarn test     # run the test suite
yarn serve    # serve the front-end on port 6969
```
